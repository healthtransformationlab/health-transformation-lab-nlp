# PerioBench

Trustworthy electronic dental records: finding gum disease in the record (phenotyping),
de-identification, and related case-finding work.

This folder holds bench-facing notes and prompts. The study code, synthetic charts, answer
key and metrics live in the usual places:

- Labels and statuses: `python/health_transformation_lab_nlp/labels.py`
- Synthetic charts / notes: `synthetic.py`, `notes.py`, `scripts/10_build_study.py`
- Metrics: `eval/`, `docs/edr/`, `docs/results.md`
- Specs: `specs/` (PerioBench-related)

OralHealthBench and AccessBench sit beside this folder under `benchmarks/`.
