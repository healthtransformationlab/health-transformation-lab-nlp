# PR Review: the missing-value mask works on pandas 2 and 3

## Summary
`tooth_loss_dq._is_missing` now builds its mask column by column and treats `object` and `str` columns as text, so
Load Open Dental no longer crashes on Databricks (pandas 2) and blank text counts the same everywhere.

## Checks against the rubric
- **Test first:** the regression test failed under pandas 2.2.3 (the crash) and under pandas 3 (blanks not counted)
  before the fix, and passes under both after.
- **Results:** the data-quality page is regenerated by its script; only the missing-value share changes
  (0.47% to 2.59%), because blank text is now counted.
- **Spec:** none needed; a bug with a regression test.
- **Parity:** no R twin covers this check.
- **Telemetry:** no new public function.

## Findings
- **Minor (no change):** CI runs pandas 3 only, so a pandas-2-only failure can recur elsewhere. Running the test suite
  against the Databricks runtime's pandas too would catch this class; left for a separate change.

## Verdict
Approve.
