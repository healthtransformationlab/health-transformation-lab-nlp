# Data sources: what's synthetic here, and what exists elsewhere

## Synthetic notes in this repo

All generated by this repo. No real patients, no real PHI.

| File | What's in it | Rebuild with |
|------|--------------|--------------|
| `data/datasets/train.csv` | 2,426 de-identified notes from synthetic patients; 63% in the published real-note style ([note_realism.md](note_realism.md)). Labels: chart truth (`label`), the clinician's written diagnosis (`stated_status`), grade, extent | `scripts/10_build_study.py` |
| `data/datasets/review_tasks.json` | ~240 charts with every source (note, exam form, procedure codes and diagnoses completed/planned, probing chart, radiograph AI), ready for Label Studio | `scripts/10_build_study.py` |
| `data/datasets/answer_key/review_key.csv` | The same 237 charts with generator truth and each method's reading. Reviewers must not open it | `scripts/10_build_study.py` |
| `data/corpus/corpus_sample.parquet` | 3,801 notes for the cost benchmark (not committed) | `scripts/14_benchmark_cost.py` |
| `data/samples/labeled_notes_sample.csv` | 12 short templated notes from the first benchmark | `scripts/01_build_dataset.py` |

**Realism:** diagnosis lines follow forms published for real UTHealth notes; see [note_realism.md](note_realism.md).

**Limitation:** the same author wrote the note generator and the rules that read
the notes, so the rules know the generator's phrasing. That's why rule-based
scores are high on these notes. An independently written synthetic set is a
fairer test, and real notes are the real one.

## Public synthetic dental notes

| Dataset | What it has | Access | Fit |
|---------|-------------|--------|-----|
| **Synthetic Dental Clinical Notes Dataset for Dental NLP Benchmarking** ([IEEE DataPort](https://ieee-dataport.org/documents/synthetic-dental-clinical-notes-dataset-dental-nlp-benchmarking), DOI 10.21227/tt32-vp70; T. Generation method not described on the page | **Best candidate for a second, independent test set.** Check the license and review a sample before using it in a publication |

Ask the authors |
| **Cross-institutional dental EHR entity extraction via generative AI synthetic notes** ([NSF PAR](https://par.nsf.gov/biblio/10639435-cross-institutional-dental-electronic-health-record-entity-extraction-via-generative-artificial-intelligence-synthetic-notes)) | Follow-on from the same group | Not checked (page blocked automated access) | Ask the authors along with the one above |

## Public real-text datasets

Published, already de-identified and licensed for redistribution, so committed under
`data/external/<name>/` with a README (constitution v1.2.0). Evaluation and training data for their own experiments: never mixed into the
synthetic sets.


| Dataset | What it has | Access | Used for |
|---------|-------------|--------|----------|
| **MACCROBAT** (Caufield 2019, [figshare](https://doi.org/10.6084/m9.figshare.9764942.v2), MACCROBAT2020.zip; BIO mirror [`ktgiahieu/maccrobat2018_2020`](https://huggingface.co/datasets/ktgiahieu/maccrobat2018_2020)) | 200 clinical case reports from PubMed Central, edited to the case details, with hand-annotated entities (41 types: symptoms, diseases, procedures, drugs, lab values, dates, ages ...). The mirror holds the 2018 and 2020 releases of the same 200 | CC BY 4.0; committed in [`data/external/maccrobat/`](../data/external/maccrobat/README.md) (original zip, BIO splits) | De-identification test pass on real prose (original brat release by default): date recall and clinical over-redaction ([deidentification.md](deidentification.md#results-on-maccrobat-200-real-case-reports-external-spec-009), spec 009). Not dental, not chart notes |

## Public real charts (no notes)

| Dataset | What it has | Access | Used for |
|---------|-------------|--------|----------|
| **NHANES 2009–2014 oral health – periodontal** (CDC/NCHS; files OHXPER_F/G/H, OHXDEN_F/G/H, DEMO_F/G/H) | Full-mouth periodontal exam of ~11,000 US adults 30+: pocket depth and attachment loss at six sites on every tooth but third molars; tooth counts; age, sex, smoking, diabetes; survey weights and design | Public domain; downloaded at run time by `scripts/38_nhanes_perio.py --download` or the Databricks job `nhanes_perio` (cdc.gov is not reachable from every environment). Raw files are not committed | Real charts for the chart algorithms (CDC/AAP 2012, ACES); checks this repo's code against the published prevalence (Eke 2018; Tay 2025). No notes, no clinician diagnosis, no bleeding on probing, no follow-up visits (spec 013 G4) |

## Not usable for notes

| Source | Why not |
|--------|---------|
| Synthea | Generates dental encounters and procedures, but no free-text notes |
| GlobalDentBench-OA | Exam-style questions and answers, not chart notes |
| BigMouth Dental Data Repository ([references](references.md) item 84) | Real EHR data under a data-use agreement, not synthetic or public |
