Health Transformation Lab · Drill-down

OMOP is the common data format for health research. Dentistry is the open seat: its dentistry workgroup began in 2022 and reports few dental datasets converted so far. The same goes for AI benchmarks: work with the bodies that own them to add oral health. If dental data speaks that format, medicine comes to oral health without translation, and that is how oral health becomes part of overall health in practice. The knowledge carries over: OMOP is a map of how health terms relate, such as which code is a kind of which condition. The same map is what a knowledge graph and an AI search index are built from, so the skill that maps dental data to OMOP is the skill that makes frontier models more knowledgeable about oral health.
