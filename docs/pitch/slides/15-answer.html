A better answer has three parts. The human side is the story: a real person's experience, shared with consent, or a public education video. The finance side is the number: cost, visits, savings. Each number has one agreed definition, so reports, dashboards and the AI all give the same figure. The evidence is the source, one click away. A story without a number is an anecdote, and a number without a story is forgotten. Exact terms if asked: the one agreed definition of each number is a metric definition; Databricks calls it a metric view. It defines a measure once, centrally, so dashboards and AI reuse the same calculation. Order of work: the first 180 days focus on medical-dental and access-to-care questions, starting from published material. Stories and numbers come after, because stories need consent and numbers need clear definitions and safeguards.
