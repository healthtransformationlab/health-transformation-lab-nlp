Three steps from here. First, a small live run: a few models on the fifteen questions, through the batch job, with the cost recorded, so there is a first real score. Second, expert review: people who work with Medicaid, appeals and dental billing check every key point and red flag before any score is published, because a benchmark is only as good as its answer key. Third, grow the set beyond the gum check, to travel, safety-net clinics, VA dental, children's coverage and accommodations, using the same method. The north star is more people completing a periodontal screening by 2030; that is a personal stretch goal, not any organization's target. Everything is in the benchmarks/access_bench folder of the repository.
