The landing page has two paths, and this is how they meet. This path builds synthetic patients whose right answers are known, in the same format medicine uses. That makes them a source of test questions: case questions written from those patients, with the right answer already scored. The other path, OralHealthBench, is about testing AI where medicine meets dentistry and on access to care, in public. Both test AI the same way: the same models, harm grades and leaderboards, scoring AI first on gum charts, then on case questions from synthetic patients, then on broader medical-dental questions.
