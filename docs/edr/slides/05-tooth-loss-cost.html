The second question is narrower: when a tooth is missing, was it lost to gum disease? It matters because five or more teeth lost to gum disease is what makes stage 4. This one reads tables, not text: extraction codes, probing measurements, the teeth missing at the first exam. Only two kinds of model have been run, logistic regression and XGBoost, both small enough to run on an ordinary CPU, so we have not priced them; there is no costly option to compare them with, because no LLM has been run on this question. They score well on extractions whose reason was recorded and held out of training: an AUC of about 0.9. But on the teeth that were already missing at the first visit, which is what the model is actually used for, the AUC drops to between 0.59 and 0.70. And there is no pass bar yet: the analysis plan says what is measured, not what score passes. So the honest answer to "is the less costly model good enough" here is that we have not set what good enough means. That is part of the ask: the study lead sets the bar before a real record is read. If asked about other models: a comparison with more kinds of model is in progress in its own pull request; the full score table, with sensitivity and specificity, is in the appendix. All synthetic.
